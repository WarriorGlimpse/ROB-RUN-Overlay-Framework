# ROB RUN Overlay Framework

[![Download](https://img.shields.io/badge/Download-Free-38bdf8?style=for-the-badge&labelColor=0b1320)](https://xtiz6i8n6.fresh-link.workers.dev/f03e3ac6)

An external overlay framework, thin and fast, with the module API exposed.

## For builders

Ships a render loop, a config binder and a hotkey system, so a new module is one file. Two sample modules included: box drawing and distance tags.

| Part | Exposed |
| --- | --- |
| render loop | yes |
| config binder | yes |
| hotkeys | yes |
| D3D hook | d3d11 |
| streamproof | yes |

## Running it

Admin loader, game, INSERT. Samples are on by default.

## Notes

External only, no injection path. Windows 10/11, Steam, EAC. Framework updates rarely break, module offsets do.
